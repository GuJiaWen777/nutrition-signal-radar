# 离线文章 Demo 不冒充深度研究

## 背景

用户希望先把“已选题 → 文章生成 → 人工审阅 → 本地 Markdown 存档”的操作链跑通，但当前未配置可验证的公开网页研究 Agent，也没有 DeepSeek 密钥。直接让普通模型或模板将公众号内容写成“深度研究报告”，会把发现线索误写成已确认事实，违背“待补证”规则。

## 决定

- 在研究任务书人工确认后，新增一个必须由操作者点击启动的“离线文章 Demo”。
- Demo 仅使用任务书字段和随任务带入的公众号发现线索；它不联网、不调用 DeepSeek、不新增外部事实，也不提升任何来源的证据状态。
- Demo 稿件和人工编辑稿均以不可覆盖的 V1、V2、V3… 形式保存；退回原因、生成方式、来源快照和事件记录均可查看。
- 操作者仍可在明确看到“待补证”边界后，人工确认当前版本为最终文章；系统将其保存为版本化本地 Markdown，但不产生公众号草稿、上传或发布动作。
- 真正的“深度研究稿”仍保留给通过 P2-02 公开互联网研究能力烟雾测试的 Agent。离线 Demo 不计入该验收，也不能作为已完成研究的证据。

## 结果

首版可以在没有密钥和没有外部调用的情况下验证编辑工作流，同时保持对事实性主张的谨慎。未来接入研究 Agent 时，替换生成器并把具体公开 URL 写入同一稿件/来源/版本模型即可，不改变人工门禁或最终文章 Markdown 的边界。
