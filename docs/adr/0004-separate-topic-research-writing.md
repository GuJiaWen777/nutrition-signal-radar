# 分离选题、深度研究与公开写作

选题包、研究任务书、深度研究报告和未来公开文章是不同产物。选题进入深度研究前、研究报告进入任何下游用途前，都必须可由人工直接查看，并经过显式的确认、退回或停止决策。

这会增加独立状态、数据表和界面，但可以避免未确认的选题自动消耗研究资源，也能防止缺少证据或仍有争议的研究结论直接变成公开内容。

当前扩展止于可审阅的深度研究报告，不自动生成或发布公开文章。
