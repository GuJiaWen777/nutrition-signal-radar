# 将营养健康行业信号雷达保持为独立衍生项目

营养健康行业信号雷达首阶段作为 `extensions/content-topic-radar/` 下的独立衍生项目存在，采用“同一仓库、独立子项目”的组织方式。它不是现有 EarlyData Weekly Publisher 的功能模块，也不修改其代码、命令、状态机、配置、文档或行为。这个阶段建立了长期行业信号、选题与研究工作流所需的安全边界；2026-08-14 的独立仓库迁移由 [ADR-0010](0010-independent-repository-migration.md) 取代此目录组织决定。
