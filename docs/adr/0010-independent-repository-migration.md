# 将营养健康行业信号雷达迁移为独立 Git 仓库

首阶段的独立子目录已验证产品和数据边界，但继续留在周报仓库会让版本所有权、发布节奏和运行状态边界不够清晰。项目现以 `GuJiaWen777/nutrition-signal-radar` 独立维护，只迁移代码、测试、文档与示例配置；`.env`、`.venv` 和 `var/` 继续是本机私有状态，不进入新仓库。历史 Weekly Publisher 保持不变，双方不共享运行库、数据库、密钥或发布路径；需要复用外部 Demo 输入时，由操作者显式提供只读文件路径。
