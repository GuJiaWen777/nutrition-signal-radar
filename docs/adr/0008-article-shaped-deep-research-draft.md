# 首版合并深度研究与文章初稿

## 背景

最终内容发布在微信公众号，目标读者需要简洁、可读的行业判断型文章。若深度研究 Agent 先生成复杂报告，再由另一流程改写文章，会增加状态、审阅和版本管理成本，不符合第一版保持简单的要求；但直接写文章又可能丢失来源链、冲突证据和不确定性。

## 决定

- 选题包和研究任务书继续分开，并保留研究启动前的人工门禁。
- 深度研究 Agent 首版直接生成“深度研究稿”：正文采用微信公众号文章结构，文末保留来源、待补证、冲突证据和不确定性说明。
- 深度研究稿经过人工事实审阅和编辑修改后直接成为最终文章，不再要求额外生成一份独立研究报告和一次“报告转文章”任务。
- 最终文章确认与微信公众号发布授权仍是两个独立动作；当前扩展不自动发布。

## 结果

首版只维护一条研究与写作主线，减少重复生成和审阅，同时保留证据可追溯性。若未来需要同时交付内部咨询报告和对外文章，再把两种产物拆开。
