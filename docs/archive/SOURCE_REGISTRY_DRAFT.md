# 重点网站清单草案

状态：Working Draft。它是未来可编辑配置的内容种子，不是已经启用的抓取或研究配置。

## 1. 来源与边界

本清单从 `D:/Earlydata/2026-Q2.html` 的 84 条参考记录中提取。排除 Google Fonts 等页面资源后，共得到 31 个内容域名、34 个不同参考 URL。

这批来源有两个明显局限：

- 67/84 条记录指向企业、品牌或原料商域名，适合观察竞品和企业动作，但不足以单独支撑监管、科研或功效判断。
- 71/84 条记录只指向官网首页或语言入口，不是具体文章、公告、论文或文件页面。

因此，本清单采用以下规则：

1. 它是“优先来源清单”，不是严格白名单；深度研究 Agent 在证据不足时仍可检索其他互联网公开资料。
2. 官网首页只用于发现内容，不能直接作为具体事实的证据链接。
3. 进入选题包或深度研究稿的事实证据必须保存具体文章、公告、论文、活动页或文件 URL。
4. 企业官网只能直接证明该企业自己的公开动作或主张；功效、科研和监管结论仍应补充论文、监管文件或其他适当的一手来源。
5. 媒体、转载平台和用户内容平台默认用于发现线索；未经原始来源交叉核对，不得把相关主张标记为“已核实”。
6. 首版只使用互联网公开资料，不接入付费数据库、内部数据库或第三方账号。

## 3. 尚未包含的来源类别

`2026-Q2.html` 中没有形成可直接复用的监管与学术来源清单。后续应单独验证并补充：

- 中国及重点海外市场的监管、法规和标准网站。
- 开放论文、论文摘要、临床试验和科研机构网站。
- 企业公告的具体栏目或 RSS / 检索入口，而不只登记企业首页。
- 公开行业统计、协会和展会数据网站。

在逐个验证准确域名、可访问性和证据用途前，这些类别不预填具体网站。

## 4. 未来可编辑字段

每个重点网站建议至少支持：名称、域名、来源类别、来源角色、优先级、启用状态、适用主题、证据规则、备注、来源出处和最后校验时间。

停用某个重点网站只表示不再优先检索，不会把它变成系统级屏蔽域名，也不会限制 Agent 检索其他互联网公开来源。
